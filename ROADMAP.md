# Roadmap

## Near term

- Stable component lifecycle and error context.
- Retry and checkpoint primitives without compromising the small core.
- First-party HTTP and SQL plugin packages.
- Structured run events for observability integrations.

## Later

- Typed configuration schema and editor completion.
- Plugin discovery through Python entry points.
- Reusable pipeline templates and a public component catalog.

Roadmap items are proposals, not commitments. Discuss priorities in GitHub Discussions.
